## Yenilikler

- Kütüphaneler güncellendi: Claude için Anthropic SDK 3.3.0 (yeni API sürümü 2026-10-21), script'lerin JavaScript
  motoru Rhino 1.9.2, sunucu Ktor 3.6.1, ayrıca JSON, JWT ve QR kitaplıkları. Görünür bir değişiklik beklenmez.

## Deneysel

Aşağıdakiler gerçek cihazda henüz denenmedi; sorun görürseniz Loglar ekranının görüntüsüyle bildirin.

- Claude ile sohbet ve YZ adımları yeni SDK ile gerçek bir API anahtarıyla denenmedi. SDK anahtarı artık farklı bir
  başlıkla gönderiyor (API'nin bunu kabul ettiği doğrulandı). Claude kullanıyorsanız ve hata görürseniz bildirin.
- Script'ler yeni JavaScript motoruyla telefonda denenmedi (otomatik testler geçti). Bir script önceki sürümde
  çalışırken artık hata veriyorsa bildirin.

## Güncellerken

- Konfigürasyon sürümü değişmez.

**English:** Libraries updated: Anthropic SDK 3.3.0 for Claude (new API version 2026-10-21), the Rhino 1.9.2 JavaScript
